# Interacting refinement and task comparison evidence

The report, tables, figures, fixed study design, training metadata, comparison results and warm timings are retained here. Large JSON files use lossless gzip; their original and archive SHA-256 checksums are recorded. Full restorable checkpoints, physical-noise banks and reference/predicted trajectories remain in the local run directory indexed by `archive_manifest.json`.

All optimizer seeds are retained separately. Pointwise finite-reference intervals do not certify continuous stopped-DK convergence.
