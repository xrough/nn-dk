Large JSON is losslessly gzipped. No covariance PDE residual alone is a prediction-error certificate.

Exact frozen source bytes and packaging metadata are under `code/`. The informational Git HEAD does not assert that uncommitted or untracked scripts existed in that commit. Full native polygons, Brownian arrays, raw family JVPs, compiled libraries, validation banks and binary model weights remain local with checksummed inventories. Original absolute metadata paths and original bytes have not been rewritten.
